About Swift Cart

Swift Cart is a simple e-commerce web application built using Django. It allows users to browse electronic products like smartphones, laptops, and headphones.

Our Goal

The goal of this project is to create a user-friendly online shopping platform where users can explore products easily and learn the basics of web development.

Technologies Used

  • Python
  • Django Framework
  • HTML & CSS

Learning Purpose

This project is developed as part of learning Django and web development concepts.
