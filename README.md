# 🛒 Swift Cart – E-Commerce Web App

🚀 Swift Cart is a simple e-commerce web application built using Django.
It allows users to browse products, add items to cart, and manage their shopping experience.

---

## 📌 Features

* 🏠 Home Page with modern UI
* 🛍️ Product Listing Page
* ➕ Add to Cart functionality
* ❌ Remove from Cart
* 🧾 Cart Page with total calculation
* ℹ️ About Page (project info)
* 📞 Contact Page

---

## 🛠️ Technologies Used

* Python 🐍
* Django Framework
* HTML5 & CSS3
* Bootstrap (UI Styling)

## ⚙️ How to Run

```bash
# Clone the repo
git clone https://github.com/kalpprajapati/swift_cart_miniproject.git

# Go into folder
cd swift_cart

# Create virtual environment
python -m venv venv

# Activate
venv\Scripts\activate   (Windows)

# Install Django
pip install django

# Run migrations
python manage.py migrate

# Start server
python manage.py runserver
```
